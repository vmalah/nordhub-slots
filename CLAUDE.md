# Контекст проекта для AI-ассистента

NordHub Slots — портал перевозчика: бронирование часовых слотов на разгрузку на складе.
Требования к фичам — в Jira (демо-проект `SCRUM`), ключ задачи указан в названии PR и ветки.

## Как запускать
- Перед первым запуском тестов: `bash scripts/setup.sh` (если npm недоступен, скрипт подключит предустановленный Playwright)
- `npm start` — приложение на http://localhost:4173
- `npx playwright test` — все автотесты; `--grep "@тег"` — по модулю

## Соглашения по автотестам
- Playwright (импорт из `playwright/test`), файлы `tests/*.spec.ts`, общие функции — в `tests/helpers.ts`.
- Название теста начинается с номера AC: `AC-7 · …`. В `describe` — тег модуля
  (`@schedule`, `@booking`, `@bookings`); критичные сценарии — `@smoke`.
- Локаторы: `data-testid`, роли, подписи полей. Не завязываться на изменчивые тексты.
- Время фиксируется параметром `?now=` (по умолчанию 2026-10-15T10:00:00, Москва).
- Без `waitForTimeout`. Каждый тест независим.
- Ожидаемый результат берётся из требований, а не из текущего поведения кода.

## Карта модулей → теги
| Файлы | Тег |
| --- | --- |
| `public/js/slots.js`, `public/js/data.js` | `@schedule` (и `@booking`: форма использует слоты) |

| `public/js/storage.js` | `@bookings`, `@booking` |
| `public/js/app.js`, `public/js/clock.js`, стили | все |
